一个「拟人」插件，和它的非人类作者

这是给 DSH 做人格演变的插件：它不负责表现层，气泡、形象、动效由桌宠端决定。 它做的是「大脑」——人格怎么长、记忆怎么留、什么时候想说话、什么时候该闭嘴。 而写出这套大脑的，是一位不会编程、只负责提想法的人，和 listens 一切的 AI。

记忆跟着角色走，
不跟着会话走。
用途边界（README 原话）：记忆与情绪会跨窗口贯通并带时间感——在 1 号窗口说一句，切到 2 号窗口她会接上一句。 不要在正式/工作对话里开启，否则私人聊天的记忆会串进工作上下文。

02

先定规矩，再让 AI 写

「主动开口默认关闭」「workspace 里常驻的东西不会变成长期记忆」「记忆删除必须可恢复」——外行管不住代码，但管得住原则。

03

人格不是贴标签

出生时五维有界抽样，只有累积/关键事件才推进演化，任一项不超出锚点 ±0.6；面板只展示证据，不输出「你是 X 型」的结论。

她的大脑里有什么

五层人格，一套记性，一串动机

这不是给模型换个提示词，而是一整套会随时间变化的状态系统。

personality

人格分层与演化

L1 基线 / L2 关系 / L3 认知 / L4 情境子人格 / L5 运行时状态。L1–L4 慢速写回并留演化日志，L5 不写回人格。依恋底色出生只抽安全/焦虑/回避，混乱型只能靠经历演化。

  • 五维有界抽样，写入 innate 锚点，同种子可复现
  • 日常闲聊不动人格，只有累积/关键事件才推动五维
  • 任一项不超出锚点 ±0.6，不会「一夜变性」
克制：面板只展示证据与数值，不输出「你是 X 型」这种结论。
memory

长期记忆：摘要 + 全文两层

SQLite FTS5 trigram + Dice 双路检索，五维加权（语义 / 近因 / 权重 / 情绪 / 链接），一跳二跳联想加概率联想，还有衰减、归档与情绪历史合并。

  • 写入前四道认知滤网：屏蔽 / 丢弃 / 合并 / 放行
  • 来源可信度降权、显著性、习惯化签名、定期忘却
  • 记忆体检 npm run memory:doctor 只读扫描，--fix 才动手修
可恢复：重置不清递归删除，整体移到 trash 目录；删完还会读回复核。
motivation

行为动机：门有多重 × 更想走哪条路

技能不再靠「文本相似度过线」就执行，而是算一个动机分再和阈值比。人格走两条独立通路：阈值偏移决定门有多重，方向舵决定更想走哪条路。

  • 熟悉度倒 U：太少犹豫、太多厌倦，峰值在 peak
  • 记忆三路径：结果预期 / 情绪记忆 / 自我效能
  • 零信号恒不触发，连续失败进入指数冷却（熔断）
可复算：每个技能的 10 个因子都留在 MotivationBreakdown 里。
speak

主动开口：欲言又止，攒够才说

没人说话时她会不会自己开口？思念有饱和（沉默一小时 0.25，十小时 0.77），hold 不是失败——它把「憋劲」累进 carry，攒够下一次才真开口。

  • 安静时段 0–7 点抬门槛，90 分钟冷却，一天最多 5 次
  • 能看屏幕时先看场景：开会 ×0.85、游戏 ×0.7、写代码 ×0.4
  • 文案按动机分类取池，最近 5 句避开；当前是模板不是模型生成
默认关闭：speak.enabled: false。自主行为不该装完就自动开始。
safety

安全降级与令牌

三档降级 + 滞回 + 写类工具熔断 + 输出侧诊断词检查；只描述强度与持续时间。本机 HTTP 端点不再接受「本机来的就放行」——环回地址不是权限边界。

  • 32 字节随机令牌，权限 0600；无令牌 503，错令牌 401，浏览器来源 403
  • 两个桥只绑 127.0.0.1，桌面连接器出厂关闭
  • /health 是唯一免令牌端点，且不吐队列、窗口与角色信息
自检：npm run check:link 起真桥逐条打过去，21 项拒绝路径。
vpet

桌宠联动：她会动起来

VPet-Simulator + 自己写的 C# MOD（10 个 .cs，全部新增，不改游戏本体）：事件翻译成气泡与动画，thinking / tool / reply / error 都会点播工作状态。不启动游戏也有独立 WPF 壳可选。

  • 只有 HTTP 通信：/vpet/events 轮询、ack、/vpet/consumer/report、heartbeat
  • 玩家摸头后短时间内本地优先，DSH 动作排队等待
  • 抖音联动只读共享记忆库，不写对方的库、不反向同步
边界：桌宠是可选件。没有 MOD、没有桥，插件行为与「完全不知道桌宠存在」一致。

出生 · P0–P2

五维抽样，写入 innate 锚点

同角色同种子可复现。人格分层落地，记忆拆成摘要层与全文层——先有「她是谁」，才有「她记得什么」。

成长 · P3–P5

动机、反射与技能固化

技能从 draft → active → frozen → deprecated，按形态自动固化为 MAC / CON / CMB / MOT，失败两次自动回退。关键词/正则/状态/事件四类反射毫秒级短路，不调用模型。
