# dsh-daughter 0.8.4 更新说明

> 基线：0.8.3 · 日期：2026-11-27

## 角色卡与「她是谁」

- 设置面板新增「她是谁」页：名字、自称、称呼对方、一句话背景、说话风格、绝不主动提起。手写部分注入在 persona 块最前面，优先于由经历推演出的性格，不参与演化；空卡不产生任何文本。
- 同一页上半按记忆自动整理她现在的样子：名字、最强三项性格措辞、关系阶段与亲密度、共同经历条数、最近 30 天常聊主题、喜恶、重要的人；下半留空字段就沿用记忆与自动整理的结果。
- 旧版本只存在对话记忆里的名字会被自动补进角色卡：从事件里按高精度句式提取候选，至少出现两次才认，问句与泛称不算，已有名字不会被覆盖。

## 人格控制

- 新增「人格」页：五维滑块与出生锚点、依恋两维、自我叙事三轴；可逐项锁定，锁定同时作用于事件驱动与语气微调两条演化路径，三维全锁时整轮不写盘、不记证据。
- 演化总开关关闭后，五维、依恋与自我叙事不再随经历移动；记忆、关系、情绪与技能不受影响。
- 支持手填五维：保存时同步改写出生锚点并重算气质，避免下一次演化被漂移上限夹回。
- 支持按种子重抽初始人格：只换五维、气质与依恋底色，保留关系进度、对人情感、记忆、技能与日常情绪，并记录种子便于复现。

## 画像与自读

- 新增「画像」页：她眼里的自己、主人、其他人与稳定喜恶，与 prompt 注入共用同一套画像计算。
- 新增工具 `daughter_self`：她可按需读取自己的角色卡、五维、依恋、自我叙事、关系、锁定状态与演化开关；每次调用都重新读取，设置改完或重抽后立即反映，只读不写。
