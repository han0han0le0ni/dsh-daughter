# dsh-daughter 0.8.3 更新说明

> 基线：0.8.2 · 日期：2026-11-25

## 主动陪伴与接管边界

- 主动开口可进入当前会话，由模型生成真实回复；支持会话选择、日上限、最小间隔和干跑，离线时退回原有表达出口。
- 新增只读插件探测与接管清单，识别已有出口、候选插件和在线状态；人格接管默认干跑，写入前快照，可一键还原，不碰凭据、连接参数与核心设置。
- 修复 cordis 未注入服务的属性访问导致宿主引导失败的问题。

## 记忆、心情与对人情感

- 检索时间项改为艾宾浩斯保留率，默认稳定度 120 天；情绪强度与事件重要度会延长保留，可关闭并退回旧算法。
- 新增可共存的心情成分与对人情感：喜悦和悲伤、亲近和怨意不再互相平均；两者共同参与语气提示。
- 脑星图 L2/L5 展示上述成分与“爱恨共存”“苦乐参半”标记，兼容旧存档。

## 技能学习与管理

- 多步工具操作先生成待确认提案，通过会话或桌宠主动询问；确认后进入影子试用，达到真实样本数与胜率才转正。
- 相同工具集合的顺序变体不再重复建卡；技能编号寻找空缺值，避免覆盖现存卡。
- 星图支持多选删除无用技能，包含二次确认、角色与路径校验；删除后清空 prompt 缓存，固化资产保留。
